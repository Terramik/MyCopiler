# MyCopiler

Простой компилятор из моего языка в С. Написан на Python.

Был создан после того, как я смог создать калькулятор, и делал я его потому что люблю делать прикольные штуки

Для документации самого языка см "LanguageDescriptions.html"

# Запуск компилятора
Для начала, компилятор собирался при: Windows10, Python 3.13.7, gcc 15.2.0 и может не работать на вашей машине.

Для работы понадобиться компиляторы Python(3.10+) 0 С(c99+), и ar(архиватор) как минимум.

Чтобы запустить компилятор, в консоли запустите файл Main/Main.py как модуль от родительской директории, где лежит весь компилятор.

# Пересборка стандартной библиотеки

Для начала, встроенная библиотека скомпилирована под Windows10, так что
выполните <запуск компилятора> retransfer_std_modules для её перекомпиляции.

Пример: python -m Test.TheLanguage.test2.Main.Main retransfer_std_modules

# Сама компиляция

Вам понадобиться основной файл .mylang как вход, и путь к файлу-результату(без расширения) как результат. <запуск компилятора> 
<путь к входу> <путь к результату>.

Сначала введите путь к основному файл исходного кода(можно относительный, тогда как отправной путь будет использована 
директория, из которой в консоли запущен компилятор). И путь куда будет записан результат.

Пример: python -m Test.TheLanguage.test2.Main.Main Test/TheLanguage/test2/scripts/game_of_life/main.mylang Test/TheLanguage/test2/scripts/result
