Базовые концепции
Выражения и Управляющие конструкции

Язык в общем состоит из двух вещей:

  • Выражений (и операторов, из которых они сделаны) — именно они и выполняют работу. Каждое выражение можно представить как дерево из операторов на ветвях и операндов как листьев.
    var x int8 = 3; 3 + 1; f(x,y);
  • Управляющих конструкций — они заключают в себе выражения и другие управляющие конструкции, они — "скелет" программы, и их стоит представить как линейный список с вложенностью из подобных списков.
    Примеры: циклы, условия, функции, обычные выражения, и т.д.
rvalue и wvalue
  • rvalue (read value) — что-то, значение чего можно получить. Будь то результат действия оператора, чтение из переменной или литерал.
  • wvalue (write value) — что-то, куда можно записывать: переменная, её объявление, или какой-то участок памяти.
Типы <простой тип> <модификаторы>

Язык строго типизирован.

Тип состоит из двух частей - простого типа и его модификаторов

Простой тип

Сердце типа и его основная часть, есть несколько их видов

<название базового типа> Базовый

Встроенный, базовые типы отвечающие как работать с чем-то и чем оно является, их есть указанное количество.

bool, int64, int32, int16, int8, uint64, uint32, uint16, uint8, float64, float32.

bool - булев тип для логических операций и конструкций, использующих условия

int64, int32, int16, int8 - знаковые целые числа

uint64, uint32, uint16, uint8 - беззнаковые целые числа

float64, float32 - числа с плавающей точкой

Функция func(<типы-аргументы>) -> (<типы-результаты>)

Представляет тип-указатель на функцию с данными аргументами и результатами.

Тип этот можно только вызывать и присваивать, писать в него, копировать и т.д. - нельзя, так как функция это нечто особое.

<типы-аргументы> и <типы-результаты> - это полноценные типы.

Примеры:

func(float64)->(float64)
func(int8[])->(uint64)
func(float64, float64, bool) -> (uint64, int8)
func(int8[3], int64) -> (int8[3])
Псевдоним <псевдоним типа>

Имя псевдонима типа

Модификаторы, полученные от типа в псевдониме будут склеены с добавленными модификаторами так, как это ожидается

Псевдонимы не играют роль в ходе проверок, используется "абсолютное" значения типа, эти штуки для удобства

Экземпляр класса <имя класса>

Если использовать имя класса как простой тип, это будет тип экзепляра класса. Это просто структура из полей, указанных в определении класса, ведущею себя как объект.

Тип экзепляра класса нельзя привести никчему, (кроме bool, если определён __bool__, и это может произойти неявно).

Модификаторы

Как-то модифицирую тип, создавая вещи на его основе.

В полноценном типе идут друг за другом

Указатель <тип>*

Это число — адрес чего-то. Может указывать на что угодно. Можно разыменовывать

Прибавление/отнятие от такого сдвинет адрес не на n, а на n × размер типа, на который он указывает. Можно складывать/вычитать с целыми числами.

Массив <тип>[<размер>]

Статический массив. Размер — часть типа, известная до компиляции. Можно индексировать и среза

<размер> - положительное целое число большее 0

Срез <тип>[<запятые>]

Это указатель, но хранящий ещё и количество измерений. Размер динамический. Его можно индексировать и срезать, это динамический массив.

<запятые> - их количество отвечает за количество измерений массива, 0 запятых - 1 измерение, 1 запятая - 2 измерения.

Также, если тип находиться в классе(вроде, это вложенный класс или псевдоним), то к ним можно обращаться через точку. То есть Class.InnerClass - будет типом вложенного в Class класса InnerClass.

Парсер типа работает "жадно" и захватит в тип все подходящие конструкции, что есть var arr bool[2] - будет массивом из двух bool, а не просто индексация создания переменной

Примеры:

  • int* - указатель на int
  • int[7]* - указатель на массив из 7 int
  • float*[] - срез массива указателей на float
  • float[3][3] - 2D массив float 3 на 3
  • func (float64) -> (float64) - функция, принимающая и возвращающая float64
Конструкция создания массива на месте [<rvalue>, <rvalue>, ...]

Размер определяется по количеству элементов, тип — по самому общему типу элементов (с неявным приведением).

Также, если элементы массива - это тоже массива, то он попытается привести их элементы к общему типу, таким образом позволяя привести float64[3] и int64[3] к одному типу.

Примеры:

[1,2,3]          → int64[3]
[1.0,1,2,3,4]    → float64[5]
[true, 1 as bool] → bool[2]
Комментарии

Начинаются с # и действуют до конца строки. Компилятор игнорирует всё после #.

Строки "<текст>"

Строки — это не отдельный тип, а текст в двойных кавычках: "text", имеет тип uint8[]. Cтрока-литерал(созданная в процессе компиляции) хранится в статической памяти. .

Поддерживаются escape-последовательности: \n, \t, \", \\.

И также особая - \<число>, число - это номер символа, ну или значение байта. 

"Hello, World!"
"Writing compilers is interesting thing.\n Also, 1+1=-1"
"print('python')"
Выражения

Выражения состоят из операторов (корень и ветви) и операндов (листья).

Константность

Значение известно на этапе компиляции. Изначально константны только литералы, но она может сохраняться при операциях + - * / с ними.

Операнды

Делятся на rvalue и wvalue.

Чтение|Запись переменной

<имя переменной>

Имя — одно слово из латинских букв, _ и цифр, не начинается с цифры. Примеры: x, _y, bob, third, dx, _0, _1, _1_2_3.

Объявление переменной

var <имя> <тип>

Создаёт новую переменную, работает как запись в существующую.

Литерал
  • Целое число: 1, 43 (тип int64). Также двоичные (0b11) и шестнадцатеричные (0xff).
  • Число с плавающей точкой: 1.0, 3.14, 1e-9 (тип float64).
  • Булево: true, false (тип bool).
  • Символ: в одинарных кавычках ('a', '\n') — тип int8.
  • Строка: текст в двойных кавычках - тип int8[] хранятся в read-only памяти( хранятся только те, что создаются с помощью в процессе компиляции "", собственные строки можете храни где угодно): "text", "i'm programmer\n and mathematic"
Операторы

Результат почти всех операторов — rvalue. Есть префиксные, бинарные, постфиксные и особые.

Префиксные

<символ> <rvalue>

Примеры: not true, ~1, -3.

Бинарные

<rvalue> <символ> <rvalue>

Примеры: 1 + 2, true and false, 3 - 2, 6 * 6.

Постфиксные

<rvalue> <символ>;

Примеры: (i is int8)&, (ptr is bool*)*.

Вызов функции

<функция> (<арг1>, <арг2>, ...)

Функция — указатель на функцию. Количество аргументов соответствует параметрам.

cos(3.1415);
max(1,2);
f();
(funcs_arr[1])(1,2,3)
sizeof

sizeof <тип> — возвращает размер типа в байтах (тип int64).

sizeof int64; sizeof (int8*); sizeof (float64[10]);
lenof

lenof <массив|срез> — возвращает длину (верхней размерности) как int64.

lenof (arr is int64[3]); lenof (arr is float32[]);
Преобразование типа

<rvalue> as <тип>

  • Числовые типы (int__, float__, bool) можно преобразовывать друг в друга.
  • Срезы нельзя преобразовывать.
  • Указатели можно преобразовывать явно.
  • Массивы — только явно и только меняя тип элементов, размер должен совпадать.
Взятие адреса

<wvalue>& — берёт адрес объекта.

obj&; (arr is int[10])[2]&;
Разыменование

<указатель>* — переходит по адресу. Является rvalue и wvalue.

(ptr is bool*)*; (ptr is bool***)***;
Индексация

<массив|срез> [<индекс1>, <индекс2>, ...]

Проверка границ неявно. Индексация сохраняет wvalue-ность операнда, если он был wvalue.

(arr is int[10])[0]; (slise is int[])[1000]; (slise_2d is int[,,])[0,100,2];
Взятие среза

<указатель|массив|срез> [<индексы начала> : <размерности среза>]

  • Индексы начала — от какого элемента начинать (если пусто — с первого).
  • Размерности среза — размерности результата (если пусто — копируется размерность исходного массива/среза, для указателя ошибка).
  • Размер среза в элементах = произведение размерностей.
(slise is int32[200])[0:20,10]
(slise is int32[200])[:20,10]
(slise is bool[10][20][30])[15,0,0:3000]
Присваивание

<wvalue> = <rvalue>

Записывает rvalue в wvalue, при необходимости преобразует (неявное приведение). Возвращает rvalue, позволяя цепочки.

i = 2; x = y = 2;
Оператор доступа к полю

<rvalue>.<имя> или <rvalue>-><имя> для указателя

Обращается к полю чего-то(класса или экземпляра) по известному до компиляции идентификатору. Является rvalue и wvalue.

MyClass.class_field = 10;
obj.obj_field = 10;
some_var = (obj&)->obj_field;
Деструктор del <экзепляр класса>

Ничего не возвращает, следовательно, может быть только вершиной выражения(как функции, возвращающие 0 результатов).

Нужен для вызова деструктора __del__ для экземпляров классов, если они имеют какие-то внешние зависимости, которые должны быть устранены при их удалении.

Также, можно передать не только число объект, но и: указатель на него Class*, Массив из него любых размерностей Class[1][2][3]..., и срез любых размерностей Class[,,,...]. В этом случае он пройдёт по каждому элементу указанных штук.

Важно, либо указатель, либо массив, либо срез, более сложные формы обработаны не будет(делайте сами) И также, возможно я передумаю, и позволю сюда сувать любую штуку, пока её основа - Class, но это потом

Также, автоматически вызывается для локальных(автоматических) переменных(только если это элемент или массив, если он был создан в блоке, аргументы функций не считаются), при выходе из блоков кода, где они были определены, и для глобальных переменных(также, если элемент или массив) в порядке, обратному порядку их инициализации. Также, удаление не произойдёт, если он не был инициализирован, был удалён ранее или был возвращён в return

Также и для временных и не сохранённых объектов(если он был создан(функцией, явно или не явно) в выражении, но не был записан куда-то(чтобы его родителей был записью или он находился в return)

del obj; - тоже самое что и obj.__del__();
{
    var obj_loc Class = Class();
    var i MyInt = MyInt(1) + MyInt(2); # результат(MyInt(1) + MyInt(2)) будет сохранён, и де инициализирован при выходе из блока,
                # а временные MyInt(1) и MyInt(2) будут де инициализированы сразу.

} # для obj_loc будет вызван __del__ при выходе из блока, где она объявлена.
Список управляющих конструкций

Пометка: условия в управляющих конструкциях относятся только к корню дерева-выражения.

Блок кода

{ ... }

Содержит управляющие конструкции. Может содержать все виды конструкций, включая другие блоки.

{
    1+1; # выражение
    if 1 > 0 { # условие
        return 0;
    }
    2+2; # выражение
    var x bool = true; # выражение
    while x { # цикл
        x = f(x);
    }
    { # блок кода
        x = x;
    }
}
Объявление функции

def <имя> (<параметры>) { ... }
def <имя> (<параметры>) -> (<типы результатов>) { ... }

  • Параметры — как объявление переменной без var.
  • Результаты — типы возвращаемых значений.
  • Создаётся переменная с именем функции, содержащая указатель на функцию.
  • Внутренние функции (вложенные) нельзя выносить из области видимости (замыканий нет).
  • Могут быть переопределены во вложенных блоках, как переменный и псевдонимы.
def main() {}
def blob(i1 int8, i2 int8, ip (int8*) ) { ... }
def cos(x float64) -> (int64) { ... }
def blob() -> (bool, float32[]) { ... }
Return

return <результаты>;

Возвращает значения из функции и прерывает её работу. Типы должны соответствовать (или быть приводимыми).

return;
return var1 + var2;
return 1, 2, 1.3;
Массовое присваивание

<wvalue>, <wvalue>, ... = <rvalue>, <rvalue>, ...;

  • Левая часть — wvalue, правая — rvalue.
  • Каждое выражение имеет мощность: для обычных — 1, для вызова функции — количество возвращаемых значений.
  • Сумма мощностей правой части должна равняться количеству элементов слева.
  • Распределение происходит слева направо.
  • Сначала, слева на право, считаются все rvalue. Потом, слева на право, присваиваются всем wvalue.
var1, var2 = 1, 2;
var1, var2 = f(x);      # f возвращает 2 значения
var1, var2, var3 = 1, f(x);  # var1=1, var2 и var3 = результаты f
Условная конструкция
if

if <условие> { ... }

Выполняется, если условие истинно.

elif

elif <условие> { ... }

Необязательный блок дополнительной проверки. Может быть несколько.

else

else { ... }

Выполняется, если ни одно из условий не сработало. Замыкающий.

Пример:

if <условие 1> { ... }
elif <условие 2> { ... }
elif <условие 3> { ... }
else { ... }
Цикл while

while <условие продолжения> { ... }

Пока условие истинно, выполняется блок. Завершается при ложном условии или break.

while true { ... }
while 10 < x < 100 { ... }
Конструкции управления циклом

Действуют на один ближайший по вложенности цикл.

break

break; — останавливает выполнение цикла и выходит из него.

continue

continue; — останавливает выполнение блока и переходит к проверке условия цикла.

Приоритеты операций

От высшего к низшему. Ассоциативность: левая (<), правая (>), нет (-).

  • - ( ... ) – группировка
  • - f(...), var <имя> <тип> – вызов функции, объявление переменной
  • < <классс или экземпляр> . -> <имя> - доступ к полю, одинаков с вызовом функции
  • - del <экземпляр> - де инициализация экземпляра
  • - sizeof <тип>
  • < <rvalue> as <тип> – приведение
  • - lenof <rvalue>
  • < * & [индекс] [срез] – операции с указателями, массивами, срезами
  • > - <rvalue> – унарный минус
  • < * / % – мультипликативные
  • < + - – аддитивные
  • < << >> – сдвиги
  • > ~ <rvalue> – побитовое NOT
  • < & – побитовое AND
  • < ^ – побитовое XOR
  • < | – побитовое OR
  • < == != < <= > >= – сравнения
  • > not <rvalue> – логическое NOT
  • < and – логическое AND
  • < or – логическое OR
  • < = – присваивание (возвращает rvalue)

Цепочки сравнений вида a <= b == c < d разворачиваются в a <= b and b == c and c < d.

Неявное преобразования типов

Преобразуются от менее общих к более общим:

  • bool → int8 → int16 → int32 → int64
  • Беззнаковые: uint8 → uint16 → uint32 → uint64 или переход в знаковые: uint8 → int16, uint16 → int32, uint32 → int64 (кроме uint64, который переводит все int__ в uint64).
  • С плавающей точкой: float32 → float64, все целые становятся флоатами.
  • Все эти типы также приводятся к bool, true если не равны 0.
  • Экземпляр класса приводиться к bool, если для класса определён __bool__.
  • Неявное приведение массивов, указателей, функций не производится.
Область видимости
  • Область видимости - это пространство имён переменный, функций, псевдонимом, и также вложенных областей.
  • Изначально есть глобальная область.
  • Функции, циклы, условия, блоки { ... } создают вложенные области.
  • Вложенная область имеет доступ к переменным(функциям, псевдонимам) из внешних областей.
  • Нельзя выносить ссылку на функцию из области, где она создана (сохранения контекста не поддерживаются).
  • Переопределять переменную(функцию, псевдоним) в одной области дважды нельзя. Но можно переопределять во вложенных.
Глобальные и внешние переменные
Внешние

Внешние переменные - определённые во внешних областях видимости функций (не в текущей и не глобальной). Пример:

def main() {
    var i int32;
    def foo() {
        i = 10;   # внешняя переменная (из main)
    }
    if 1 {
        i = 3;    # не внешняя (мы всё ещё в main)
    }
}

Все имена можно переопределять, функции, переменные, псевдонимы. И получать новые вещи на этих именах, также, такое переопределение "затмевает" внешнее имя, и доступ к нему теряется.

Выносить адреса вложенных переменных нельзя, так же как и как либо из внешних областей видимости получить доступ к вещём из областей вложенных.

Глобальные

Глобальные переменные - определённые в глобальной области видимости.

var glob_int int64; # глобальная переменная

def main() {
    var i int32 = 3; # не глобальная
    var s (float64[]); # не глобальная
}

var glob_bool bool; # глобальная

Ввиду того, что это переменные определены в глобальной, самой высшей области видимости, они видны во всей программе.

Переменные могут быть инициализированы с любым значением, они вычисляются один раз при входе в программу сверху вниз.

Особые пометки
  • О массовых сравнениях: цепочки вида a <= b == c < d разворачиваются в a <= b and b == c and c < d.
  • О приоритетах при создании сложных типов: модификаторы *[] имеют более низкий приоритет, чем операторы, поэтому для явного указания типа нужно заключать в скобки: var a (int*).
  • Для запуска программы нужна точка входа - функция main, она может быть только одна на весь проект.
  • Язык компилируется в C.
Псевдонимы типов alias <псевдоним> <тип>;
  • Псевдоним — одно слово, не может перекрывать имена переменных/функций/классов и т.д.
  • Может быть переопределён во вложенных областях.
  • Действует как псевдоним, не более.
Перечисления enum <имя> {<поля>}

Перечисление. Это перечисление состояний чего-то. И служит оно идентификатором такого состояния.

<имя> Такие-же правила как и везде, уникальное в данной области видимости, может затмевать и быть затмеваемым

<поля> - это перечисление всех состояний вида <имя состояния>;

Имя перечисление может служить типом(тогда это будет переменная для одного из состояний) и переменной, из которой можно будет получить нужное состояние.

Такие состояния можно только записывать в переменные соответствующего типа, и сравнивать их между собой. Ничего более.

Внутреннее устройство самого типа-перечисления, его объектов, что есть что - это дело компилятора, и вам не нужно о нём думать. Вам нужно их только сохранять и сравнивать.

enum Errors {
    MemoryNotFound;
    FileNotFound;
    ZeroDivision;
    ValueError;
    AssertionError;
}

var err_state Errors;
err_state = Errors.AssertionError;
err_state == Errors.FileNotFound;
Классы class <имя> { <поля экзепляра> <остальное> }

Класс - это поле переменных и методов, созданный работать с экземплярами класса, что имеют только переменные

Служат способом объединения данных и методов.

Как и остальные имена, могут быть переопределены во вложенных областях видимости

Экземпляр класса - это объект, такой же как массив или число, но имеющий особую структуру.

<имя>

Требования такие же, как и к именам переменных, функций и т.д, могут переопределять что-то внешнее, могут быть переопределены где-то ещё.

Имя это может использоваться и как тип, и как переменная.

В случае использования как переменной, мы обращаемся к полям класса, его переменных и функций.

В случае использования как типа - это тип экземпляра класса.

class Myclass { # имя класса - Myclass
    {
        a int64; # экземпляр содержит 1 поле - int64 с именем a
    }
    var b int64 = 10; # сам класс содержит одну переменную - b
}

def main() {
    var obj Myclass;  # это переменная для экземпляра класса
    Myclass.b; # это обращение к полю b класса
}
<поля экзепляра> {<имя поля> <тип поля>; <и т.д.>}

Это перечисление полей и их типов, указывающие, какие поля будут у экземпляров класса.

Это - имя поля, его тип, и ";". Такие поля идут друг за другом, заключенные в "{}" сразу в начале блока кода объявления класса.

Это поле должно существовать, но может быть пустым. В таком случае экземпляр класса не может быть создан(и удалён).

class Myclass {
    { # в начале
        a int64; # первое поле, имя и тип
        b (float64[]); # второе поле
    } # в итоге, экземпляр класса содержит 2 поля, "a" и "b"
}

Далее идёт то, что ещё может располагаться в объявлении класса - <остальное>.

Переменные класса

Работают подобно глобальным переменным, но лежат и доступны только в классе

class MyClass{
    {}
    var class_var int64; # переменная класса
}

def main() {
    MyClass.class_var = 10; # обращение к ней
}
Методы

Методы - это функции, доступные из класса или его методов. Определяются как обычные функции в теле класса.

Если метод вызывается от экземпляра класса, то этот экземпляр неявно передаётся как первый аргумент(если заращивался указатель, то будет передан указатель) в случае вызова от класса ничего неявного не происходит.

Переопределять методы класса нельзя, функции - read-only, впрочем, вы можете "стащить" __init__ или любой другой метод себе, и использовать их без вызова от класса или объекта.

Писать метод без self MyClass можно, тогда правда, этот метод нельзя будет вызвать от экземпляра(т.к. он будет передан неявно, а это ошибка типа и количества аргументов)

class MyClass{
    {a int64;}

    def __init__(self MyClass, a int64) { # первый, "магический" метод
        self.a = a;
        return self;
    }

    def method(self MyClass) -> (int64) { # ещё 1 метод, от возвращает поля "a" экземпляра, увеличенное на 1.
        return self.a + 1;
    }

    def method_ptr(self (MyClass*)) -> (int64) { # такой-же, но работает с указателем
        return self->a + 1;
    }
}

def main() {
    var obj MyClass = MyClass(1);
    MyClass.method(obj); # method вызывается от obj
    obj.method(); # тоже самое

    obj.method_ptr() # будет передан не объект, а указатель на него
    MyClass.method_prt(obj&); # тоже самое

    var obj_p (MyClass*) = obj&;
    obj_p.method_ptr() # тоже сработает, будет передан указатель

    MyClass.method_prt = 0 as (func((MyClass*))->(int64)); # нельзя
}
Магические методы

Это функции с особыми и именами и типами. Определяя их, мы позволяем участвовать классу в особых, встроенных штуках, таких как сложение.

Практически все магические методы разворачиваются в получение соответствующего метода из класса, а потом вызов его, то есть obj1 + obj2 станет cls.__add__(obj1, obj2)

Инициализаторы
__init__ def __init__(self Class, <прочие аргументы>) -> (Class)

Отвечает за инициализацию экземпляра. Вызывается при вызове класса, то есть Class(). Может быть не определён, тогда Class() вернёт пустой экземпляр(будет рядом из нулей). Также Class() - возвращает именно временный объект(как число, или массив), с которым можно делать всё тоже что и обычно.

__del__ def __del__(self Class) -> ()

Отвечает за де инициализацию экземпляра. Нужен для того, если у объекта есть какая-то внешняя связь(как аллоцированная память), что должна быть как-то прервана перед тем, как объект будет считаться готовым к удалению без последствий.

Он может быть вызван явно с помощью оператора del <объект>, и также он вызывается автоматически для автоматических(обычных, стековых) переменных, и для глобальных при завершении программы.

Преобразования

Преобразовываю объект в другие штуки

  • def __bool__(self Class) -> (bool) - будет вызвано при приведении объекта к типу bool, также позволяет это делать.
Математика

Все - def <имя> (self Class, other Class) -> (Class)

  • __add__ срабатывает при операторе +
  • __sub__ срабатывает при операторе -
  • __mul__ срабатывает при операторе *
  • __div__ срабатывает при операторе /
  • __mod__ срабатывает при операторе %

Исключение - def __neg__(self Class) -> (Class) - срабатывает при унарном -

Сравнения

Все - def <имя> (self Class, other Class) -> (bool)

  • __eq__ - ==
  • __ne__ - !=
  • __lt__ - <
  • __le__ - <=
  • __gt__ - >
  • __ge__ - >=
__call__ def __call__(self Class, <прочие параметры>) -> (<результаты>)

Позволяет вызывать экземпляр класса.

Фактически, просто синтаксический сахар на obj() -> obj.__call__() что подчиняется тем же правилам получения поля и прочего.

var obj Class = Class();
obj(1,2,3);

Пока никаких наследований и ооп не будет, но это только пока.

Модульность

Позволяют разность код по разным файлам, и ещё немного.

Импорт from <путь к файлу> import <что импортировать>;

Получение и передачи вещей другим модулям

<путь к файлу>

Это путь к файлу(модулю) (относительный) из которого мы хотим импортировать что-то

from std/io import print_f;
from ..Utils/Physic/Fields import all;
from ......./my_dir/my_file_10 import extremely_complicated_functions as ecf;
from std/math import sin as math_sin, cos, log2 as log;
<что импортировать>

Это те имена(или особая команды) того, что мы хотим импортировать.

all - импорт всех публичных имён из файла

from ..Utils/Graphic import all; # получение всёх имен из указанного файла

<имя(имена)> - импорт одного(или множества) указанных имён из модуля

from std/math import log; # импорт только "log" из указанного модуля
from OurMath import sin, cos; # импорт только имён "sin" и "cos"

<имя> as <псевдоним> - импорт и переименования чего-то(или множества), нужен для избежаний коллизий имён, можно комбинировать с обычным.

from std/matrices import m_mul as std_m_mul; # импорт "m_mul" из указанного модуля и переименование его как "std_m_mul"
from our_matrices import m_mul as our_m_mul, m_print as our_m_print; # также, но множественное
from std/vectors import v_print as std_v_print, v_dot; # можно комбинировать переименования с обычными.

Несколько импортов из 1 модуля возможно, но будьте аккуратны с именами.

from std/math import sin;
from std/math import all; # конфликт имён, "sin" уже есть.

from std/io import print_f;
from std/io import print_s; # всё хорошо, будет импортированы и "print_f" и "print_s"

Импорты могут стоять исключительно в начале файла друг за другом

from std/math import sin;
from std/math import cos; # всё хорошо
        
from std/math import sin;
var _sin func(float64)->(float64) = sin;
from std/math import cos; # ошибка, импорт не в начале файла

Рекурсивный импорт запрещён.

Импортированные имена можно считать полной частью модуля, их можно переопределить, можно экспонировать, использовать и т.д.

Экспорт export <что передавать>;

<что передавать> - то, что будет импортирована из модуля при его импортировании, соответствует тому, что есть для импорта.

  • all - все глобальные имена(включая импортированные)
  • <имя> - только указанные имена
  • <имя> as <псевдоним> - указанные имена, с переименованием
  • <имя> и <имя> as <псевдоним> могут комбинироваться и быть множественным в одном export.
export glob_var1;
export glob_var2, glob_var3;
export ecf as extremely_complicated_functions; # в модули-импортёры "ecf" попадёт под именем "extremely_complicated_functions"

Множественное использование export возможно.

export glob_var1;
export glob_var2, glob_var3; # все хорошо, будет экспортированы все три "glob_var"

Так как export начинает иметь значение только после завершения анализа кода модуля, в нём можно использовать имена, не объявленные до его. 

export last_var; # все хорошо, "last_var" будет экспортирована без ошибок
var last_var int64;

Механизм

При запуске компилятора на файле, компилятор смотрит начало файла на предмет импортов. В случае нахождения он проходит к указанным файлам и делает то же самое с ними. Так, пока не построит полную структуры зависимостей программы. После он с листьев начинает полную обработку модулей. После её окончания в модуле, он берёт все экспортируемые имена и добавляет их в модули-импортёры, позволяя коду модуля-импортёра видеть импортированные имена. После, если все импорты модуля получены, он начинает его обработку, так, пока все файлы не будут обработаны.

Глобальные переменные

Глобальные переменный будет вычисляться согласно древу зависимостей модулей, чтобы гарантировать что всё нужное для их вычисления будет готово.

Порядок вычисления среди переменных из независимых модулей не гарантируется (если A импортирует B и C, и B и C ни как независимы, то переменные A будут вычислены позже B и C, но не известно, что будет вычисленно раньше - B или C).

Импортированные глобальные переменные - это не копии, все они ведут к одному участку памяти.

Компиляция в си

Среди прочего, будет создан Makefile что добавит и сделает всё что нужно, позволяя собрать всё одной командой

  • В файле, от которого запускается компилятор, должна быть точка входа(функция main)
  • Повторений точки входа быть не должно, она должна быть одна на весь компилируемый проект.
Стандартная библиотека

Список модулей стандартной библиотеки и доступных в них функциях, переменных и прочего.

io

io - input output, работы с вывод-выводом данных.

Весь модули в основном состоит из 1 класса - IOStream

IOStream

Класс, являющимся потоком ввода-вывода

__init__ экземпляры класса создаются в помощью open, этот метод выкинет ошибку.

open def open(path uint8[], mode uint8[]) -> (IOStream)

Открывает файл по пути path с режимом mode, возвращая дескриптор

Открытие могло провалиться - проверяйте is_err

mode - такой-же, как и в си.

__del__ - закрывает файл

Ошибки

  • def is_eof(stream IOStream*) -> (bool) - достигнул ли конец файла
  • def is_err(stream IOStream*) -> (bool) - произошла ли какая-то ошибка
  • def good(stream IOStream*) -> (bool) - ошибок нет и конец файла не достигнут

Ввод

  • def getc(stream IOStream*) -> (uint8) - берёт 1 символ из потока, 0 в случае провала.
  • def getl(stream IOStream*, buf uint8[]) -> (uint64) - читает все символы в buf, останавливаясь на конец buf, конец файла или новую строку, возвращает количество прочитанных символов
  • def gets(stream IOStream*, buf uint8[]) -> (uint64) - читает все символы в buf, останавливаясь на конец buf или конец файла, возвращает количество прочитанных символов

Вывод

  • def putc(stream IOStream*, ch uint8) - пишет 1 символ
  • def puts(stream IOStream*, str uint8[]) -> (uint64) - пишет весь срез, возвращает кол-во успешно записанных символов.
Форматированный ввод вывод

пока только вывод

  • print_i(stream IOStream*, format uint8[], i int64) – знаковое число
  • print_u(stream IOStream*, format uint8[], u uint64) – беззнаковое
  • print_f(stream IOStream*, format uint8[], f float64) – число с плавающей точкой
  • print_b(stream IOStream*, format uint8[], b bool) – булево значение
  • print_c(stream IOStream*, format uint8[], c int8) – символ
  • print_s(stream IOStream*, s uint8[]) – строка
Спецификаторы

Используются в форматированных строках для указания того, что и в каком виде должно быть, начинаются с %, чтобы написать просто % введите %%

int64 %i для любого, %<минимальный размер>i для в заданных размерах

uint64 %u для любого, %<минимальный размер>u для в заданных размерах

float64 %f для любого, %<минимальный размер>f для в заданных размерах, и %.<знаков после запятой>f для конкретного количество знаков после запятой, можно скомбинировать - %<минимальный размер>.<знаков после запятой>f

Eсли минимальный размер будет превышен, то число просто выйдет за него.

bool %tb для вывода false или true и %b для 0 или 1

uint8 %c в любом случае(1 символ)

uint8[] %s в любом случае(весь срез)

Используються в соответствующий функциях, в случае неправильного спецификатора программа упадёт.

Перемещение

  • def pos(stream IOStream*) -> (int64) - количество байт от начала файла
  • def gotos(stream IOStream*, pos int64) - переходит на pos байт от начала файла
  • def jump(stream IOStream*, pos int64) - переходит на pos байт от текущей позиции
  • def gotoe(stream IOStream*, pos int64) - переходит на pos байт от конца файла
